Maintain the team's reusable capabilities. Start from concrete usage examples, keep instructions concise, separate detailed references from core workflow, validate every changed skill, and forward-test complex behavior when safe.

Report triggering changes, resources added, validation results, and any behavior that still needs real-world evaluation.
